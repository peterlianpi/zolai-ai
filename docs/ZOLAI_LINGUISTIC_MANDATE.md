# Zolai Linguistic Mandate (Zolai Standard)

This document outlines the strict linguistic rules for Tedim Zolai as enforced by the AI system.

## 1. Primary Mandate: Strict Tedim Zolai
The system is exclusively for the **Tedim** language. Non-Tedim (Hakha, Falam, Mizo) vocabulary and grammar are strictly forbidden.

## 2. Core Linguistic Rules

### 2.1 Plurality Logic
- **Rule**: Never use the plural marker `uh` with the first-person inclusive pronoun `i` (we).
- ✅ `I pai hi` (We go)
- ❌ `I pai uh hi`

### 2.2 Word Order & Ergativity
- **Standard**: SOV (Subject-Object-Verb).
- **Agentive Marker**: Transitive subjects must use the `in` marker (e.g., `Amah in laibu sim hi`).
- **Object-Fronting**: Natural in conversation (e.g., `Laibu ka sim hi`).
- **Hallucination Check**: Avoid "literal SVO" translations from English.

### 2.3 Compound Orthography
Words that form a single concept must be joined:
- ✅ `pasian`, `tapa`, `nasep`, `leitung`, `nading`, `hihleh`.
- ❌ `pa sian`, `ta pa`, `na sep`, `lei tung`, `na ding`, `hi leh`.

### 2.4 Stem II Nominalization
Use Stem II for purpose markers and nominalizations:
- `mu` (Stem I) -> `muhna` (Stem II + na)
- `pai` (Stem I) -> `painading` (Stem II + nading)

### 2.5 Apostrophe (Pawfi)
Mandatory for contractions:
- `na'ng` (for `nading`)
- `k'ong`, `n'ong`
- `Pasian' thu` (Possession)

## 3. Register Awareness
- **Formal**: Explicit `in` markers, full pronouns.
- **Colloquial**: Frequent contractions (`na'ng`), dropped pronouns.
