# Zolai Datasets

Build + mirror high-purity bilingual datasets. The repo holds scripts and pointers,
never large blobs — data lives on HuggingFace Hub / Kaggle.

## Goals
1. Corpus build (bible 31K pairs, dictionary 21K entries, news, synthetic).
2. Dedupe + normalize + ZVS 2018 cleaning pipelines.
3. Release datasets to HF `peterpausianlian/*` and Kaggle.
4. Manifest/versioned mirrors; repo stays lean.
