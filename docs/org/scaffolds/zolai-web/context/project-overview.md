# Zolai Web Platform

Next.js (App Router) + Hono + Prisma learner platform: dictionary UI, curriculum,
chat panel, mind map, contributions. Consumes Zolai Core REST API.

## Goals
1. Dictionary search UI over Prisma-backed entries.
2. Translation demo + chat connected to the core model API.
3. Curriculum lessons + contributions pipelines.
4. Deployable on Vercel; Prisma + SQLite (dev) / Neon Postgres (prod).
